Speed

Random fill

Fill and Clear both reset the generation count and all depletion, and neither changes whether the simulation is running.

Tool

Tap to arm or disarm a colour, or use the number keys. Arm more than one and every drawn cell — brush, spray, fill, shapes and paste alike — picks from them at random.

Drag to paint. The first cell you touch decides whether the stroke writes live or dead.

Selection none

Select drags a box and Copy keeps its shape. Drop it with the Paste tool, which follows the pointer and lands in whichever colours are currently armed. On hexagons and triangles the landing point snaps to a cell of matching orientation so the shape survives.

Editing mode

Off by default: rule, mask, threshold and wrap edits are held until you press Apply, so the running field keeps its behaviour while you set up the next one. Ctrl+Enter applies, Ctrl+Backspace reverts.

Presets

Ember is Conway plus depletion: crowded cells burn out, sparse ones recover.

Adversaries off

Every colour plays by the same rules. A new cell goes to whichever colour holds the most live neighbours. Pick which colour you draw as on the Run tab, or press 1–6.

Editing mode

Same switch as on the Rules tab. Off by default: edits wait for Apply.

Depletion threshold off

Every cell carries a reserve counter. While this is off the whole depletion pass is skipped and costs nothing. While on, any cell whose counter reaches the threshold is forced dead and stays dead until the counter falls back.

Depletion neighbourhood 8 cells

Which offsets feed the counter roll. Live and dead cells both roll.

Counter step per live neighbour

One roll per generation. A hit moves the counter by one — up by default, down when − is ticked. 0% never fires, 100% always fires.

Tiling

Cells are square, so every neighbour offset is the same on every row.

Grid 70 × 50

Untick the link to set columns and rows yourself. Odd size trims a column and a row so the field has one exact middle cell. Resizing resamples what is already drawn.

Colour source

Live cells shade by their death chance, dead cells by their birth chance.
