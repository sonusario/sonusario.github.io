# sonusario.github.io

Source for [Sonusario's Selects](https://sonusario.github.io/), a hub for my web projects.

## Projects

- [Daylight Clock](https://sonusario.github.io/normalized_daylight_clock/) ([source](https://github.com/sonusario/normalized_daylight_clock)): a clock where sunrise is always 6:00 AM and sunset is always 6:00 PM.
- [Moiré Exploré](https://sonusario.github.io/moire_explore/) ([source](https://github.com/sonusario/moire_explore)): layer two patterns and explore the moiré fringes between them.
- [Probabilistic-Cellular-Automaton](https://sonusario.github.io/Probabilistic-Cellular-Automaton/) ([source](https://github.com/sonusario/Probabilistic-Cellular-Automaton)): Conway's Game of Life with probabilistic rules and adjustable neighborhoods.
- [OpColorGraph](https://sonusario.github.io/OpColorGraph/) ([source](https://github.com/sonusario/OpColorGraph)): graph every value of a slider at once, with the difference shown as a shift in hue.
- [IntervalTimer](https://sonusario.github.io/IntervalTimer/) ([source](https://github.com/sonusario/IntervalTimer)): interval timer with per-interval images, drawings, or video.
- [Physical Fitness Progression Paths](https://sonusario.github.io/physical_fitness_progression_paths/) ([source](https://github.com/sonusario/physical_fitness_progression_paths)): a training calculator with progression paths, weekly plans, fuel, recovery and gate tests, exporting to IntervalTimer.
- [Build Your Own Idle Game in Godot](https://sonusario.github.io/build_your_own_idle_game_in_godot/) ([source](https://github.com/sonusario/build_your_own_idle_game_in_godot)): a branching, click-by-click Godot tutorial from first click to a published idle game.
- [Mini PWA Engine](https://sonusario.github.io/mini_pwa_engine/) ([source](https://github.com/sonusario/mini_pwa_engine)): a visual builder for dependency-free web apps, with generated servers and a terminal version.
- [Frontend Flashing](https://sonusario.github.io/frontend_flashing/) ([source](https://github.com/sonusario/frontend_flashing)): flashcards for front-end skills, from first tags to an installable web app.
- [Flashcards](https://sonusario.github.io/flashcard_app/) ([source](https://github.com/sonusario/flashcard_app)): spaced-repetition flashcards with markdown, images, audio, and Anki import.
