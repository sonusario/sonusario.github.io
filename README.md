# sonusario.github.io

Source for [Sonusario's Selects](https://sonusario.github.io/), a hub for my web projects.

## Projects

- [Moiré Exploré](https://sonusario.github.io/moire_explore/) ([source](https://github.com/sonusario/moire_explore)): layer two patterns and explore the moiré fringes between them.
- [Flashcards](https://sonusario.github.io/flashcard_app/) ([source](https://github.com/sonusario/flashcard_app)): spaced-repetition flashcards with markdown, images, audio, and Anki import.
- [IntervalTimer](https://sonusario.github.io/IntervalTimer/) ([source](https://github.com/sonusario/IntervalTimer)): interval timer with per-interval images, drawings, or video.
- [Probabilistic-Cellular-Automaton](https://sonusario.github.io/Probabilistic-Cellular-Automaton/) ([source](https://github.com/sonusario/Probabilistic-Cellular-Automaton)): Conway's Game of Life with probabilistic rules and adjustable neighborhoods.
- [OpColorGraph](https://sonusario.github.io/OpColorGraph/) ([source](https://github.com/sonusario/OpColorGraph)): graph every value of a slider at once, with the difference shown as a shift in hue.
